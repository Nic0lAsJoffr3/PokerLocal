# PokerLocal

PokerLocal é uma plataforma web para jogar poker com amigos em mesas privadas, usando fichas virtuais e sem dinheiro real.

O host cria uma partida e define as regras da mesa: fichas iniciais, small blind, big blind, aposta mínima e incremento mínimo para aumentar. Os jogadores entram pelo código da sala e acompanham tudo em tempo real.

## Funcionalidades

- Criar partida privada
- Entrar em uma partida por código
- Definição de fichas iniciais e blinds
- Controle de dealer, small blind e big blind
- Ações de passar, pagar, aumentar, all-in e desistir
- Acompanhamento de pote, apostas e fichas de cada jogador
- Confirmação do vencedor pelo host
- Transferência automática do pote para o vencedor
